# プライバシーポリシー / Privacy Policy

対象：koyomiya-uploader（YouTube チャンネル「こよみ屋」の運営者が使う個人用の投稿ツール）

利用する情報：このツールは Google アカウントの認可を使い、運営者自身の YouTube チャンネルへの動画のアップロードと、アップロード先チャンネル名の確認だけを行います。それ以外のデータにはアクセスしません。

保存と共有：認可情報（トークン）は運営者のパソコンにだけ保存します。取得した情報を第三者に送信・共有・販売することはありません。Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

連携の解除：Google アカウントの「サードパーティのアプリとサービス」から、いつでも解除できます。

This tool uses Google OAuth only to upload the operator's own videos to the operator's own YouTube channel and to confirm the channel name. Tokens are stored only on the operator's computer. No data is shared with, sent to, or sold to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account settings.
